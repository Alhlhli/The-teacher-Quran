المصحف المعلم - جزء عم (نسخة الويب المستقلة) - الإصدار 2.7.0
=============================================================
المطور: عامر الحلحلي (https://alhlhli.github.io/)

محتويات الحزمة:
---------------
1. index.html            : الصفحة الرئيسية (تعمل مباشرة في المتصفح على الكمبيوتر والهاتف).
2. style.css             : التصميم والثيمات الستة وعارض المصحف.
3. tajweed-fonts.css     : تعريف خطوط مصحف التجويد الملونة.
4. app.js                : محرك التلاوة، التجديد التلقائي المباشر للروابط، مزامنة الكلمات، التفاسير، والذاكرة المحلية.
5. quran-data.js         : بيانات السور (الفاتحة وجزء عم) والنص العثماني.
6. qcf4-data.js          : خط مجمع الملك فهد (QCF4) وهيكلة أسطر المصحف.
7. tajweed-data.js       : بيانات مصحف التجويد الملون.
8. quran-timing.js       : توقيت الكلمات والآيات لجميع القراء التسعة.
9. chapter-studies.js    : بيانات موسوعات السور (التسمية، اللطائف، العمل بالسورة، الفضائل، الخصائص).
10. almatny-data.js      : بيانات موسوعة «علمتني السورة».
11. midad-audio.js       : البذرة الاحتياطية لروابط القراء من منصة مداد.
12. basmala-svg.js       : مسارات البسملة المتجهة (SVG).
13. tafsir/              : تسعة تفاسير كاملة لجميع الآيات، كل كتاب في ملف مستقل
                           (muyassar, saadi, ibnkathir, baghawi, qurtubi, tabari,
                           jalalayn, mokhtasar, waseet). يُحمَّل الكتاب عند أول اختيار له فقط.
14. manifest.webmanifest : ملف تطبيق الويب (PWA).
15. 3ama.ico             : أيقونة البرنامج.
16. Assets/              : خطوط المصحف (Fonts) وعناوين السور الزخرفية (SurahTitles).

طريقة التشغيل (بدون بايثون أو خادم خارجي):
------------------------------------------
- محلياً: افتح ملف `index.html` مباشرة في أي متصفح حديث، دون الحاجة لتثبيت بايثون أو أي سكربتات خارجية.
- عبر الويب: ارفع كامل المجلد إلى GitHub Pages أو أي استضافة ساكنة.

تجديد روابط التلاوات تلقائياً من الإنترنت:
-----------------------------------------
- يعمل التطبيق بشكل مستقل تماماً داخل المتصفح (`HTML/JS`):
  * يتحقق التطبيق تلقائياً من تاريخ صلاحية التوقيع الفعلي (`X-Amz-Date` / `X-Amz-Expires`) لروابط منصة مداد (سعد الغامدي، فارس عباد، الحصري حفص، الحصري ورش).
  * عند اقتراب انتهاء الصلاحية أو مرور 24 ساعة، يجلب التطبيق الروابط الجديدة مباشرة من الإنترنت بالتوازي عبر نقاط عبور CORS عامة (`allorigins`، `codetabs`، `r.jina.ai`، `corsproxy`) ويحفظها في ذاكرة المتصفح (`localStorage`).
  * في حال تعذر تشغيل أي ملف صوتي أثناء الاستماع بسبب انتهاء صلاحية الرابط، يقوم المشغل تلقائياً بتجديد الرابط في الخلفية وإعادة تشغيل السورة فوراً دون تدخل من المستخدم.

ملفات اختيارية (للاستخدام المحلي بدون إنترنت):
----------------------------------------------
- الصوتيات: `sound/<مجلد القارئ>/001.mp3 ... 114.mp3`
  مجلدات القراء: `minshawi, maher, abdulbari, 3zazi, mousa, hussary, ghamdi, abbad, warsh`
- صفحات المصحف المصورة: `MushafPages/<الطبعة>/001.png ... 604.png`
  الطبعات: `maknon_hafs, hefzmoyaser, maknon_warsh, aayaat, surahquran`

تحسينات الإصدار 2.7.0 (تجربة المستخدم والجوال):
-----------------------------------------------
- ux-enhancements.css / ux-enhancements.js : طبقة تحسين فوق الكود الأصلي (احذف رابطيهما من index.html للتراجع).
- شريط أدوات مدمج على الجوال، مشغل يظهر في كل التبويبات ويمكن تصغيره، أهداف لمس لا تقل عن 40-44px.
- زر المفضلة ظاهر على اللمس، زر الرجوع يعود إلى قائمة السور، دعم الارتفاع الديناميكي والمنطقة الآمنة.
- وصولية: حلقة تركيز، aria-label، تقليل الحركة، السماح بنسخ النص.
- PWA: أيقونات PNG في icons/ و sw.js (يعمل على HTTPS أو localhost فقط).
- البحث يقبل الأرقام العربية ٧٨.
