برنامج مكتبي قرآني تعليمي تفاعلي لنظام **Windows**، يجمع سور **الفاتحة وجزء عم (38 سورة)** بتلاوات تعليمية مكررة لترسيخ الحفظ والتدبر، مع مزامنة صوتية دقيقة على مستوى **الكلمة والآية**، وعرض مصحف المدينة المنورة، والتفاسير المعتمدة، والخرائط الذهنية للسور، ودعم العمل الكامل دون اتصال بالإنترنت (Offline).

* **رابط المستودع الرسمي:** [https://github.com/Alhlhli/The-teacher-Quran](https://github.com/Alhlhli/The-teacher-Quran)
* **الموقع الشخصي للمطور:** [عامر الحلحلي - alhlhli.github.io]https://alhlhli.github.io/)

## ✨ أبرز المميزات

### 1. التلاوات التعليمية والروايات (6 قراء)

| م | اسم القارئ | نوع التلاوة / الرواية | المجلد المحلي |
| :--- | :--- | :--- | :--- |

### 2. عارض المصحف التفاعلي (4 تبويبات متكاملة)
* **🖼️ تبويب المصحف (صور الصفحات):**
  * يضم **9 طبعات مصورة** عالية الدقة (مصحف التجويد الملون، مصحف الحفظ الميسر، مصحف المدينة برواية حفص، مصحف رواية ورش عن نافع، مصحف آيات، وغيرها).
  * **انتقال تلقائي للصفحات مع الصوت** في السور الممتدة على صفحتين أو ثلاث صفحات (مثل النبأ، النازعات، المطففين، الأعلى، الفجر، الليل، البينة، والعاديات).
  * دعم تقليب الصفحات للأمام والخلف عبر **عجلة الماوس (Scroll)** أو النقر على جانبي الصفحة.
* **📖 تبويب النص القرآني:**
  * **خط المصحف التفاعلي (`QCF4 - مصحف المدينة`):** تفاعل مباشر مع الماوس والصوت؛ إبراز الكلمة والآية المقروءة لحظياً، نسخ الآية بنقرة واحدة، و**الانتقال الصوتي المباشر إلى الكلمة والآية عند النقر المزدوج (Double-Click)**، مع دعم تقليب الصفحات بعجلة الماوس.
  * **خطوط العرض النصية (عرض فقط بدون تفاعل ماوس):** تشمل خط أميري القرآني (`Amiri Quran`)، الخط العثماني التقليدي، خط النسخ الواضح، و**نص رواية ورش عن نافع**.
* **ℹ️ تبويب معلومات السورة والخريطة الذهنية:**
  * يعرض بطاقة تعريفية شاملة لكل سورة (نوعها، عدد آياتها، ترتيب نزولها، رقم صفحتها في مصحف المدينة 604 صفحات، مقاصدها ومحاورها الموضوعية) مع إثراء تلقائي من موسوعة `Quranpedia`.
  * يعرض **الخريطة الذهنية للسورة** (من مصحف الحفظ الميسر) مع إمكانية فتحها وتكبيرها في نافذة مستقلة.
* **📚 تبويب التفاسير المعتمدة:**
  * يضم **6 تفاسير قرآنية** مرتبة آية بآية مع إمكانية التكبير/التصغير والنسخ والحفظ للعمل دون اتصال:
    1. **التفسير الميسر** (مجمع الملك فهد)
    2. **تفسير السعدي** (تيسير الكريم الرحمن)
    3. **تفسير الجلالين**
    4. **تفسير ابن كثير**
    5. **تفسير البغوي** (معالم التنزيل)
    6. **التفسير الوسيط** (طنطاوي)

### 3. إدارة الصوت والعمل دون اتصال (Offline)
* **مدير تحميل التلاوات والصفحات والنصوص:** تحميل سور قارئ محدد أو جميع القراء، وحفظ صفحات المصحف والخطوط والتفاسير محلياً للعمل بدون إنترنت.
* **تخصيص مسار الصوت وتشغيل ملفات خارجية:** إمكانية ربط البرنامج بأي مجلد صوتيات محلي على جهاز المستخدم أو تشغيل ملفات `MP3 / WAV` مباشرة.
* **التحكم في سرعة التلاوة والتكرار:** دعم سرعات متعددة (`0.75x` إلى `2.0x`) وأنماط تكرار مرنة (بدون تكرار، تكرار السورة الحالية، تكرار القائمة المحددة).
* **تسجيل الصوت والمراجعة الذاتية:** تسجيل تلاوة المستخدم بصوته بصيغة `.wav` في مجلد `Recordings` والاستماع إليها لمقارنة الحفظ.
* **الإحصائيات ومتابعة الجلسة الأخيرة:** تتبع عدد السور المقروءة وأيام الاستماع وسجل النشاط، مع شريط ذكي لاستئناف التلاوة من آخر سورة وآية وموضع زمني توقف عنده المستخدم.

### 4. تخصيص الواجهة واللغات والثيمات
* **6 ثيمات لونية متناسقة:** كحلي ليلي، أخضر زمردي، عسلي كهرماني، أزرق ملكي، لؤلؤي فاتح، وبيج هادئ.
* **3 لغات للواجهة:** العربية، الإنجليزية، والفرنسية.
* **وضع القراءة المركّز (`F11` / `Ctrl+M`):** إخفاء القوائم الجانبية وتكبير المصحف بملء النافذة مع شريط تحكم عائم ومختصر.

## ⌨️ اختصارات لوحة المفاتيح والماوس

| الاختصار / الإجراء | الوظيفة |
| :--- | :--- |
| **نقرتان بالماوس على الكلمة** | الانتقال الصوتي المباشر إلى الآية والكلمة (في خط المصحف QCF4) |
| **نقرة واحدة على الكلمة** | نسخ الآية كاملة مع رقمها إلى الحافظة (في خط المصحف QCF4) |
| **عجلة الماوس (Scroll)** | تقليب صفحات المصحف للأمام والخلف (في تبويب الصور وخط المصحف) |
| `Space` | تشغيل / إيقاف مؤقت للتلاوة |
| `Right` / `Left` أو `N` / `P` | الانتقال إلى السورة التالية / السابقة |
| `S` أو `Esc` | إيقاف التلاوة (أو الخروج من وضع القراءة المركّز) |
| `Up` / `Down` | رفع / خفض مستوى الصوت بمقدار 5% |
| `M` | كتم / استعادة الصوت |
| `R` | تبديل نمط التكرار (بدون تكرار / تكرار السورة / تكرار القائمة) |
| `F11` أو `Ctrl + M` | تفعيل / إيقاف وضع القراءة وتكبير المصحف |
| `Ctrl + A` / `Ctrl + D` | تحديد جميع السور (38 سورة) / إلغاء التحديد |
| `Ctrl + 1` / `Ctrl + 2` | التبديل بين الاختيار الفردي والاختيار المتعدد |
| `Ctrl + T` | تبديل المظهر اللوني (بين 6 ثيمات) |
| `Ctrl + L` | تبديل لغة الواجهة (العربية / الإنجليزية / الفرنسية) |
| `Ctrl + R` | إعادة ضبط المشغل والتحديد إلى الوضع الافتراضي |
| `F1` | عرض نافذة اختصارات لوحة المفاتيح |
