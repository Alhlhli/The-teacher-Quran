## ✨ أبرز المميزات والخواص الجديدة

### 1. التلاوات التعليمية والروايات (9 قراء للمصحف المعلم)
يضم البرنامج **9 من كبار القراء** لتلاوات المصحف المعلم (مع ترديد الأطفال/الطلاب خلف الشيخ) بروايتي **حفص عن عاصم** و**ورش عن نافع**، مع دعم الجلب الذكي للتلاوات عبر خوادم `MP3Quran` ومنصة `مداد (Midad)`:

| م | اسم القارئ | نوع التلاوة / الرواية | المجلد المحلي |
| :--- | :--- | :--- | :--- |
| **1** | **الشيخ محمد صديق المنشاوي** | المصحف المعلم (حفص عن عاصم) | `minshawi` |
| **2** | **الشيخ ماهر المعيقلي** | المصحف المعلم (حفص عن عاصم) | `maher` |
| **3** | **الشيخ عبد البارئ محمد** | المصحف المعلم (حفص عن عاصم) | `abdulbari` |
| **4** | **الشيخ الحسيني العزازي** | المصحف المعلم (حفص عن عاصم) | `3zazi` |
| **5** | **الشيخ عبد الله الموسى** | المصحف المعلم (حفص عن عاصم) | `mousa` |
| **6** | **الشيخ محمود خليل الحصري** | المصحف المعلم (حفص عن عاصم) | `hussary` |
| **7** | **الشيخ سعد بن سعيد الغامدي** | المصحف المعلم (حفص عن عاصم) | `ghamdi` |
| **8** | **الشيخ فارس عباد** | المصحف المعلم (حفص عن عاصم) | `abbad` |
| **9** | **الشيخ محمود خليل الحصري (ورش)** | المصحف المعلم (رواية ورش عن نافع) | `warsh` |

### 2. عارض المصحف التفاعلي (4 تبويبات متكاملة + شريط أدوات ذكي)
* **🖼️ تبويب المصحف (صور الصفحات):**
  * يضم **9 طبعات مصورة** عالية الدقة (مصحف التجويد الملون، مصحف الحفظ الميسر، مصحف المدينة برواية حفص، مصحف رواية ورش عن نافع، مصحف آيات، وغيرها).
  * **انتقال تلقائي للصفحات مع الصوت** في السور الممتدة على صفحتين أو ثلاث صفحات (مثل النبأ، النازعات، المطففين، الأعلى، الفجر، الليل، البينة، والعاديات) مع التحميل المسبق للصفحات في الخلفية.
  * زر **«📖 تفسير السورة»** للانتقال الفوري من صورة الصفحة إلى تفسير السورة الحالية، مع إمكانية تقليب الصفحات بالأزرار أو النقر على جانبي الصفحة أو **عجلة الماوس (Scroll)** عند تفعيلها من الإعدادات.
* **📖 تبويب النص القرآني:**
  * **خط المصحف التفاعلي (`QCF4 - مصحف المدينة`):** تفاعل مباشر مع الماوس والصوت؛ إبراز الكلمة والآية المقروءة لحظياً، نسخ الآية بنقرة واحدة، و**الانتقال الصوتي المباشر إلى الكلمة والآية عند النقر المزدوج (Double-Click)**، مع خيار الخلفية الورقية (`📜 ورق`).
  * **خطوط العرض النصية (عرض فقط بدون تفاعل ماوس):** تشمل خط أميري القرآني (`Amiri Quran`)، الخط العثماني التقليدي، خط النسخ الواضح، و**نص رواية ورش عن نافع**.
* **ℹ️ تبويب معلومات السورة والخريطة الذهنية:**
  * يعرض بطاقة تعريفية شاملة لكل سورة (نوعها، عدد آياتها، ترتيب نزولها، رقم صفحتها الفعلية في مصحف المدينة 604 صفحات، مقاصدها ومحاورها الموضوعية) مع إثراء تلقائي من موسوعة `Quranpedia`.
  * يعرض **الخريطة الذهنية للسورة** (من مصحف الحفظ الميسر) مع إمكانية فتحها وتكبيرها في نافذة مستقلة، وأزرار تنقل مباشر (`▶ سورة` / `◀ سورة`) بين السور.
* **📚 تبويب التفاسير المعتمدة:**
  * يضم **6 تفاسير قرآنية** مرتبة آية بآية مع إمكانية التكبير/التصغير والنسخ والحفظ للعمل دون اتصال، وزر **«🖼️ صفحة المصحف»** للعودة السريعة إلى صورة الصفحة وأزرار التنقل المباشر بين السور:
    1. **التفسير الميسر** (مجمع الملك فهد)
    2. **تفسير السعدي** (تيسير الكريم الرحمن)
    3. **تفسير الجلالين**
    4. **تفسير ابن كثير**
    5. **تفسير البغوي** (معالم التنزيل)
    6. **التفسير الوسيط** (طنطاوي)
* **🎲 أدوات التبديل السريع في الشريط الفرعي:**
  * زر **الاختيار العشوائي (`🎲`)** للتنقل العشوائي بين طبعات المصحف أو الخطوط أو التفاسير أو اختيار سورة عشوائية للمراجعة.
  * زر **إعادة الضبط السريع (`↺`)** للعودة الفورية إلى الخيار الافتراضي وحجم الخط القياسي في التبويب الحالي.

### 3. التحديث الذكي لملفات التوقيت وإدارة التحميلات دون اتصال (Offline)
* **التحديث الأسبوعي التلقائي لملفات المزامنة (`Timing JSON`):** يفحص البرنامج مستودع GitHub الرسمي تلقائياً كل أسبوع لتحديث ملفات توقيت الآيات والكلمات في حال إضافة مزامنات جديدة، مع إمكانية التحديث اليدوي الفوري من الإعدادات.
* **مدير تحميل شامل ومفصّل في نافذة الإعدادات:**
  * **التلاوات الصوتية:** تحميل سور قارئ محدد أو جميع القراء الـ 9 دفعة واحدة في مجلد `sound` (أو أي مسار مخصص يختاره المستخدم) مع عرض عدد السور المحملة وحجمها بالميجابايت.
  * **صور صفحات المصحف:** خيار تحميل المصحف الافتراضي فقط (مصحف التجويد الملون) لتوفير المساحة، أو تحميل جميع المصاحف الـ 9 كاملة.
  * **كتب التفسير:** خيار تحميل التفاسير الافتراضية (السعدي والميسر) أو جميع التفاسير الـ 6 كاملة.
  * **النصوص والخطوط والخرائط الذهنية:** تحميل مستقل لنصوص السور (العثماني وورش وخطوط `QCF4`) والخرائط الذهنية للعمل الكامل بدون إنترنت.
* **تخصيص مسار الصوت وتشغيل ملفات خارجية:** إمكانية ربط البرنامج بأي مجلد صوتيات محلي على جهاز المستخدم أو تشغيل ملفات `MP3 / WAV` خارجية مباشرة.
* **التحكم في سرعة التلاوة والتكرار والتسجيل الصوتي:**
  * دعم سرعات تلاوة متعددة (`0.75x` إلى `2.0x`) وأنماط تكرار مرنة (بدون تكرار، تكرار السورة الحالية، تكرار القائمة المحددة).
  * تسجيل تلاوة المستخدم بصوته بصيغة `.wav` في مجلد `Recordings` والاستماع إليها لمقارنة الحفظ.
  * تتبع إحصائيات القراءة وأيام الاستماع وسجل النشاط، مع شريط ذكي لاستئناف التلاوة من آخر سورة وآية وموضع زمني توقف عنده المستخدم.

### 4. تخصيص الواجهة واللغات والثيمات (7 ثيمات)
* **7 ثيمات لونية متناسقة:** كحلي ليلي، أخضر زمردي، عسلي كهرماني، أزرق ملكي، لؤلؤي فاتح، بيج هادئ، و**أسود ورمادي**.
* **3 لغات للواجهة:** العربية، الإنجليزية، والفرنسية.
* **تخصيص كامل للأزرار والبطاقات:** التحكم في حجم بطاقات السور (4 أحجام)، وإظهار أو إخفاء أي زر في شريط الأدوات الرئيسي أو الشريط العلوي، وتغيير خط البرنامج وحجمه (`100%` إلى `140%`)، وتفعيل أو إيقاف تقليب الصفحات بعجلة الماوس.
* **وضع القراءة المركّز (`F11` / `Ctrl+M`):** إخفاء القوائم الجانبية وتكبير المصحف بملء النافذة مع شريط تحكم عائم ومختصر.

## ⌨️ اختصارات لوحة المفاتيح والماوس

| الاختصار / الإجراء | الوظيفة |
| :--- | :--- |
| **نقرتان بالماوس على الكلمة** | الانتقال الصوتي المباشر إلى الآية والكلمة (في خط المصحف QCF4) |
| **نقرة واحدة على الكلمة** | نسخ الآية كاملة مع رقمها إلى الحافظة (في خط المصحف QCF4) |
| **عجلة الماوس (Scroll)** | تقليب صفحات المصحف للأمام والخلف (عند تفعيل الخيار من إعدادات المظهر) |
| `Space` | تشغيل / إيقاف مؤقت للتلاوة |
| `Right` / `Left` أو `N` / `P` | الانتقال إلى السورة التالية / السابقة |
| `S` أو `Esc` | إيقاف التلاوة (أو الخروج من وضع القراءة المركّز) |
| `Up` / `Down` | رفع / خفض مستوى الصوت بمقدار 5% |
| `M` | كتم / استعادة الصوت |
| `R` | تبديل نمط التكرار (بدون تكرار / تكرار السورة / تكرار القائمة) |
| `F11` أو `Ctrl + M` | تفعيل / إيقاف وضع القراءة وتكبير المصحف |
| `Ctrl + A` / `Ctrl + D` | تحديد جميع السور (38 سورة) / إلغاء التحديد |
| `Ctrl + 1` / `Ctrl + 2` | التبديل بين الاختيار الفردي والاختيار المتعدد |
| `Ctrl + T` | تبديل المظهر اللوني (بين 7 ثيمات) |
| `Ctrl + L` | تبديل لغة الواجهة (العربية / الإنجليزية / الفرنسية) |
| `Ctrl + R` | إعادة ضبط المشغل والتحديد إلى الوضع الافتراضي |
| `F1` | عرض نافذة اختصارات لوحة المفاتيح |
